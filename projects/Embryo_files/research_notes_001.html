Step 1 — Opening the Dataset

The first task was to open the microscopy dataset stored in the Zarr format. 


import zarr

embryo = zarr.open(
    train_dir / "6bba_cf35214c.zarr",
    mode="r"
)

What happens here?

Unlike JPEG or PNG images, fluorescence microscopy experiments are stored as hierarchical datasets capable of containing extremely large multidimensional arrays.

Calling zarr.open() does not load the entire embryo into memory. Instead, Python creates a reference to the dataset, allowing portions of the data to be accessed only when required.

An easy analogy is opening a library catalogue rather than taking every book off the shelves at once.

Step 2 — Understanding the Object


type(embryo)


Output

zarr.core.group.Group

Interpretation

The embryo itself is not an image. Instead, it is a container that stores multiple datasets together with metadata.

Conceptually, the structure resembles:

Embryo
│
├── Images
├── Metadata
└── Labels

Step 3 — Looking Inside the Dataset


list(embryo.keys())


Output

['0']

Interpretation

The Zarr group contains one primary multidimensional array named "0", which stores the fluorescence microscopy images.

Step 4 — Accessing the Image Data


image = embryo["0"]

type(image)


Output

zarr.core.array.Array

Interpretation

This object represents the actual microscopy dataset. Unlike ordinary photographs, it is a multidimensional numerical array describing fluorescence intensities across space and time.

Step 5 — Understanding the Dataset Dimensions


image.shape


Output

(100, 64, 256, 256)

Interpretation

This became one of the most important observations during the exploration phase.

  • 100 → Time points
  • 64 → Z slices
  • 256 → Image height
  • 256 → Image width

Rather than being a single image, the embryo consists of a sequence of three-dimensional image stacks collected over time. Each time point contains 64 optical slices through the embryo.

This means one embryo contains:

100 × 64 = 6,400 individual microscopy images

Together, these slices capture the three-dimensional structure of the embryo as it develops over time, producing what is commonly referred to as a 4D microscopy dataset.

Step 6 — Extracting a Single Optical Slice

To begin exploring the dataset, I extracted a single two-dimensional image from the four-dimensional microscopy dataset. 


slice_2d = image[0, 32]

Interpretation

  • Time = 0 (the first time point)
  • Z = 32 (the middle optical slice)

The result is a single grayscale image representing one thin optical section through the embryo. Although the complete dataset is four-dimensional, most image processing algorithms operate on one two-dimensional image at a time, making this a useful starting point for exploration.

Step 7 — Displaying the Image


plt.imshow(slice_2d, cmap="gray")
plt.axis("off")
plt.show()

Interpretation

Matplotlib converts the numerical pixel intensity values into a grayscale image that can be viewed by humans.

One important realization during this step was that computers do not actually "see" images. They only process arrays of numbers, where each number represents the fluorescence intensity measured by the microscope. Humans interpret those numerical matrices as images.

Step 8 — Exploring Multiple Z Slices


z_slices = [0, 10, 20, 30, 40, 50]

To better understand the three-dimensional structure of the embryo, I examined several optical slices taken at different depths.

Observations

  • Different slices contained different numbers of nuclei.
  • Slice 0 contained relatively few visible nuclei.
  • Middle slices (approximately 20–50) contained many more nuclei.
  • The apparent size of nuclei changed depending on the slice location.

Scientific Interpretation

A nucleus is a three-dimensional object. When an optical slice passes through its center, it appears as a larger circular structure. When the slice passes near the edge of the nucleus, it appears much smaller.

This illustrates an important concept in microscopy: each two-dimensional image is only one thin section of a much larger three-dimensional biological structure.

Step 9 — Interactive Z-Stack Exploration


@interact(z=(0, 63))

image[0, z]

Purpose

Instead of manually changing the slice index each time, I used an interactive slider to scroll through the embryo along the Z-axis.

This approach closely resembles software commonly used by computational biologists, such as Napari and Fiji, where researchers navigate through volumetric microscopy data interactively.

Exploring the dataset in this way makes it much easier to understand the spatial organization of cells within the embryo.

Step 10 — Investigating Pixel Intensity Distribution


plt.hist(slice_2d.ravel(), bins=100)

What happens here?

The ravel() function converts the two-dimensional image into a one-dimensional vector containing every pixel value. Instead of examining where pixels are located, this histogram shows how bright or dark they are.

Purpose

Understanding the intensity distribution is important because many image processing algorithms depend on pixel brightness. The histogram provides insight into the dynamic range of fluorescence values and helps guide later preprocessing decisions, such as threshold selection and normalization.

Step 11 — Measuring the Intensity Range


slice_2d.min(), slice_2d.max()


Output

8
1380

Interpretation

Unlike ordinary photographs, microscopy images store raw fluorescence intensity measurements rather than values scaled between 0–255.

The intensity values in this image ranged from 8 to 1380, reflecting the amount of fluorescence detected at each pixel by the microscope.

These values represent physical measurements rather than display colours, which is why additional preprocessing is often required before applying computer vision algorithms.

Step 12 — Why Blob Detection Initially Failed

len(blobs)


Output

Interpretation

The algorithm failed to detect any nuclei.

Rather than assuming the algorithm was incorrect, this became an opportunity to ask an important scientific question:

Why did the algorithm fail?

This marked a transition from simply writing code to debugging computational methods through scientific reasoning.

Step 13 — Image Normalization


from skimage import exposure

slice_norm = exposure.rescale_intensity(
    slice_2d,
    out_range=(0, 1)
)

Purpose

The raw fluorescence intensities were rescaled from their original range (8–1380) to a normalized range between 0 and 1.

Normalization does not change the biological structures present in the image. Instead, it changes only the numerical scale, making the data more suitable for many computer vision algorithms.

An intuitive analogy is converting measurements from centimeters to meters. The object itself remains unchanged; only the units are different.

Step 14 — Verifying the Normalization


slice_norm.min(), slice_norm.max()


Output

0.0
1.0

Interpretation

The normalization step successfully transformed the intensity values into the expected range. This confirmed that the image was now ready for further computational analysis.

Step 15 — Detecting Candidate Nuclei


from skimage.feature import blob_dog

blobs = blob_dog(
    slice_norm,
    min_sigma=2,
    max_sigma=6,
    threshold=0.05
)

len(blobs)


Output

24

Interpretation

After normalization, the algorithm identified 24 candidate nuclei. These detections represent potential cell nuclei based on their appearance in the image, rather than biologically confirmed cells.

Understanding Difference of Gaussians (DoG)

Difference of Gaussians (DoG) is a classical computer vision algorithm designed to detect blob-like structures. Rather than understanding biological concepts such as cells or nuclei, it simply searches for bright, approximately circular objects of a particular size.

Since fluorescently labelled nuclei appear as bright circular regions in microscopy images, DoG provides an effective baseline method for identifying candidate nuclei before moving on to more advanced approaches.

Blob Detection Output

Each detected blob is represented as: 


[y, x, sigma]
  • y → Vertical image coordinate
  • x → Horizontal image coordinate
  • sigma → Estimated blob radius

Rather than returning images, the algorithm produces quantitative measurements describing the location and approximate size of each detected structure.

Key Takeaways

Although no artificial intelligence model was trained during this phase, this exploration established the computational foundation required for future analysis.

  • Biological microscopy data is fundamentally different from ordinary photographs.
  • Embryo datasets are four-dimensional, containing both spatial and temporal information.
  • The Zarr format enables efficient storage and retrieval of extremely large microscopy datasets.
  • Computers analyze numerical intensity values rather than visual images.
  • Image preprocessing plays a critical role before applying any computer vision or machine learning algorithm.
  • Classical computer vision methods can successfully identify candidate nuclei and provide a useful baseline for more advanced approaches.
