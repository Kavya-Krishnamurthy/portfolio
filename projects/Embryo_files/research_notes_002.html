Project Background

I started this project with a simple objective: understand how modern computational methods analyze developing embryos captured using fluorescence microscopy.

Although I have a background in Bioinformatics, I quickly realized that modern microscopy datasets are significantly different from the datasets I had previously worked with. Instead of spreadsheets or sequencing data, I was dealing with multidimensional image volumes that evolve over time.

Rather than treating this as another coding exercise, I decided to approach it as an independent research project. My goal was not simply to produce results, but to understand every stage of the computational pipeline from first principles.

Understanding the Dataset Structure

The first challenge was understanding how the microscopy data was organized.

Unlike conventional image datasets containing JPEG or PNG images, the embryo data was stored using the Zarr format. Initially this was unfamiliar territory.

After exploring the directory structure, I found that each embryo consisted of a four-dimensional image volume represented by: 

(T, Z, Y, X)
  • T – Time
  • Z – Depth (Optical Sections)
  • Y – Image Height
  • X – Image Width

This was an important conceptual shift.

I was no longer working with individual images. Instead, I was working with a living biological system evolving through space and time.

Reading Large Image Volumes Efficiently

Since microscopy datasets can easily occupy several gigabytes of storage, loading everything into memory is impractical.

I explored the Zarr storage format and learned how it enables lazy loading.

Instead of reading the complete dataset, only the requested chunks are loaded into memory when needed.

This allows efficient exploration of very large biological datasets without exhausting system resources.

Visualizing the Embryo

Once I could access the image volumes, the next objective was visualization.

Initially I displayed individual optical slices using Matplotlib.

Examining different Z planes revealed an important observation:

  • Some slices contained only a few nuclei.
  • Middle slices contained the highest concentration of cells.
  • The embryo occupies only a portion of the imaging volume.

This immediately demonstrated why analysing only a single image slice is insufficient.

The embryo exists in three dimensions, and meaningful biological interpretation requires examining the complete volume.

Interactive Exploration

To improve exploration, I developed an interactive viewer using Jupyter widgets.

Instead of repeatedly modifying array indices and rerunning notebook cells, I created sliders that allowed rapid navigation through:

  • Time points
  • Z slices
  • Individual image planes

This transformed dataset exploration from a static process into an interactive one.

Being able to scroll through hundreds of image slices significantly improved my intuition about embryo morphology.

Understanding Image Intensities

Another concept I investigated was pixel intensity.

Unlike ordinary photographs, fluorescence microscopy images represent emitted light intensity rather than color.

Each pixel stores a numerical value indicating the amount of detected fluorescence.

By generating intensity histograms, I observed that most pixels belong to the background while relatively few correspond to fluorescent nuclei.

Understanding this distribution later became important when studying thresholding and object detection.

Detecting Candidate Nuclei

Once I became familiar with the image characteristics, I began exploring methods for automatically identifying candidate nuclei.

My initial focus was on blob detection using the Difference of Gaussians (DoG) approach.

Rather than treating it as a black-box algorithm, I spent time understanding the mathematical intuition behind Gaussian smoothing, scale-space representation, and why subtracting two blurred images enhances approximately spherical structures.

This helped me understand why nuclei naturally appear as blobs within fluorescence microscopy images.

Thinking in Scale Space

One concept that significantly changed my understanding was scale space.

Objects do not appear identical at different resolutions.

Small nuclei and large nuclei require different observation scales.

By generating Gaussian representations using multiple sigma values, I observed how image structures gradually simplified as the blur increased.

This provided a much deeper appreciation of why blob detectors search across multiple scales rather than relying on a single image resolution.

From Detection to Tracking

At this stage I encountered an important realization.

Detecting nuclei solves only part of the biological problem.

The next challenge is determining whether a nucleus observed in one time point corresponds to the same biological cell in subsequent observations.

This shifted my focus from image processing toward object tracking.

Exploring Tracking Algorithms

My first implementation focused on nearest-neighbor tracking.

The underlying assumption is simple:

Since cells generally move gradually, the closest nucleus in the following frame is likely to represent the same biological object.

Although this works reasonably well under simple conditions, it becomes unreliable whenever neighboring cells move close together or exchange positions.

This revealed that cell tracking is fundamentally an identity preservation problem rather than merely a localization problem.

Introduction to Global Optimization

To overcome the limitations of nearest-neighbor tracking, I began studying assignment optimization techniques.

The Hungarian Algorithm provided an elegant solution.

Instead of matching cells independently, it computes the globally optimal assignment between two consecutive frames while minimizing the overall matching cost.

Understanding this algorithm marked my first exposure to optimization techniques commonly used in biological image analysis.

Key Lessons Learned

  • Large microscopy datasets require memory-efficient storage and loading techniques.
  • Understanding biological image formation is just as important as understanding image processing algorithms.
  • Visualization often reveals insights that numerical analysis alone cannot.
  • Detecting objects and preserving their identity are fundamentally different computational problems.
  • Many biological image analysis problems can be reformulated as optimization problems.
  • Building intuition before implementing algorithms leads to a much deeper understanding of the complete computational pipeline.
